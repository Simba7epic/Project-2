# Security Vulnerability Simulation Suite

## Overview
This project is a cybersecurity simulation developed for an academic assignment based on the community system **People’s Produce**.

It demonstrates common security vulnerabilities and defensive mechanisms through multiple interactive demos.

---

## Included Simulations

### Authentication Security
- Brute force attack simulation
- Rate limiting (delay between attempts)
- CAPTCHA verification
- Account lockout system
- IP blocking
- Combined layered security system

---

### Password Security
- Weak password demonstration
- Password strength checking tool
- Password hashing

---

### Authentication Enhancements
- Multi-factor authentication (MFA) simulation
- Login security flow improvements

---

### Exposed Endpoint Security
- Server flooding limiting
